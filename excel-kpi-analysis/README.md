# Excel Data Analysis — Georgia County KPIs

A three-sheet Excel workbook that takes messy county data from raw to a live KPI dashboard. Rebuild of a *CIS 2010 — Excel Data Analysis* project (data cleaning and transformation; KPIs on population, ZIP codes, and counties).

**Deliverable:** [`georgia_county_kpis.xlsx`](./georgia_county_kpis.xlsx) — open in Excel; every dashboard number is a live formula, not a pasted value.

## The three sheets

1. **RawData** — data as delivered: inconsistent casing (`GWINNETT`, `fulton`), stray whitespace, population stored as text with commas, a duplicate row (Cobb), and a missing ZIP value.
2. **Cleaned** — title-cased names, trimmed whitespace, numeric types, duplicate removed, gaps filled, plus a computed `PopPerZip` column (`=C/D`).
3. **KPI Dashboard** — headline KPIs and a per-region roll-up, all driven by `SUM`, `AVERAGE`, `MAX`, `MIN`, `COUNTA`, `COUNTIF`, and `SUMIF` over the Cleaned sheet.

## Finding

Population is heavily concentrated: the eight **Metro Atlanta** counties hold **71.4%** of the analyzed population, and just four counties (Fulton, Gwinnett, Cobb, DeKalb) exceed 500,000 residents each. ZIP-code density tracks this — Metro Atlanta counties average far more people per ZIP than rural counties, which matters for anything sized per ZIP (delivery zones, service coverage, sales territories).

## Reproduce

The workbook is generated by a script so the pipeline is transparent and re-runnable:

```bash
pip install openpyxl
python3 build_workbook.py    # writes georgia_county_kpis.xlsx
```
